## 5. 新增方案的留存约定

以后每做一件事，只要涉及**架构选择、数据格式或跨文件改动**，就按下面的规则留档：

1. 在 `docs/` 新建 `<主题>-plan.md`，文件名用 kebab-case；
2. 在本页「方案清单」补一行，状态用：`方案稿` / `待评审` / `实施中` / `已落地` / `已废弃`；
3. 方案至少包含：背景与目标、结论与备选、设计细节、逐文件改动、验收标准、风险、实施批次；
4. 实施完成后：
   - 把状态改为「已落地」，补上对应提交或 `notes/` 文档链接；
   - 已落地的长期技术说明写进 `notes/`，不要把 `docs/` 当运行手册；
   - 在 `CHANGELOG.md` 的 `[文档]` 分类下记一笔；
5. 方案作废也要保留，状态标「已废弃」并写一句原因，不要直接删除。
