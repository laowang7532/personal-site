1. 一个网站由什么组成

把网站想成开一家实体店，五样东西缺一不可：

页面文件 = 店里的货+ 服务器 = 店面+ 域名 = 门牌号+ DNS = 地图导航+ HTTPS = 门锁和保安

访问者的动作，本质是一串接力：浏览器输入域名 → 问 DNS「这名字对应哪个 IP」→ DNS 回答 → 浏览器去那个 IP 的 80/443 端口 → 服务器把 HTML 文件发回来 → 浏览器画出来。

所以"网站打不开"永远只有几个可能：域名解析错了、服务器没开机、防火墙端口没开、服务器上没有文件、或者证书不对。后面所有排查都是在这条链上找断点。

2. 六个必备名词

名词人话解释你实际会碰到
IP 地址服务器在互联网上的门牌数字，唯一。154.8.177.56
端口同一栋楼的第几个门。80 是 HTTP，443 是 HTTPS，22 是 SSH。轻量防火墙里一条条规则
域名给 IP 起的名字，租的，不是买的，要按年续费。xiaowang.com
DNS 解析把域名翻译成 IP 的电话簿。加了 A 记录，域名才知道往哪送。控制台里那条 A @ → 154.8.177.56
备案（ICP）中国大陆的行政要求。服务器在大陆，用域名访问就必须备案。腾讯云备案系统，要身份证
HTTPS / 证书把浏览器和服务器之间的对话加密，地址栏出现小锁。靠 CA 签发的证书实现。Let's Encrypt 免费，Caddy 自动申请

3. 完整八步流程

  1. 买服务器 已完成你已经有了：北京地域、2核2G、Ubuntu 24.04、公网 IP 154.8.177.56。
  2. 把网页文件放上去 已完成网站本质上就是几个 HTML/CSS/JS 文件，放进服务器某个目录，让 web 服务器指向它。你现在放在 /var/www/personal-site。
  3. 先用 IP 访问 已完成浏览器打开 http://154.8.177.56 能出页面，说明链路通了。这一步不需要域名，也不需要备案。
  4. 买域名在腾讯云 / 阿里云 / Namesilo 买，几十到一百块一年。国内注册商要实名认证（个人身份证，1–3 个工作日）。
  5. 添加解析（DNS）在域名控制台加一条 A 记录：主机记录 @（代表裸域）指向 154.8.177.56，再给 www 加一条。生效通常几分钟到几小时。
  6. 备案（大陆服务器必须）通过腾讯云备案系统提交，审核通过后域名才能在大陆正常访问。详见第 6 节。
  7. 配 HTTPS给域名申请证书，让 https:// 可用。用 Caddy 的话，一行配置它就自动申请和续期。
  8. 长期维护续费域名和服务器、备份数据、看监控。网站是活的，不是做完就完。

4. 域名怎么买

域名是按年租的，第一年常有优惠，续费才是真实价格。选的时候注意三件事：

  • 后缀：.com 最通用（约 60–90 元/年）；.cn 便宜（约 30–50 元/年）但备案材料多一点；.me / .dev / .im 更适合个人站，贵一些。
  • 名字：短、能拼、不用解释。xiaowang.com 比 xiaowangdegerenwangzhan.com 好一百倍。
  • 在哪买：服务器在腾讯云就顺手在腾讯云买，备案时不用跨平台倒腾。想省事也可以 Cloudflare（但 Cloudflare 注册的域名在国内备案会很麻烦）。

提醒：买域名时勾掉那些默认加购的"隐私保护""云解析套餐"，第一年很多是免费试用，第二年自动扣费。

5. 解析（DNS）是什么

你在浏览器输 xiaowang.com，电脑不认识这个名字，只认识 IP。DNS 就是那本电话簿。

最常用的两种记录：

类型作用典型写法
A 记录域名 → IPv4 地址@ → 154.8.177.56
CNAME域名 → 另一个域名（常用于 CDN、Vercel）www → xxx.vercel.app

「@」代表裸域（xiaowang.com），「www」代表 www.xiaowang.com。两个通常都要加，不然用户输哪个都可能打不开。

验证解析是否生效，在终端里跑：

dig xiaowang.com +short
# 返回你的服务器 IP 就说明解析生效了

6. 备案到底怎么回事

一句话：服务器在中国大陆，你用一个域名指向它对外提供网站服务，就必须先做 ICP 备案。这是行政法规，不是平台规定。

什么情况需要

  • 服务器在大陆（北京 / 上海 / 广州 / 成都等）→ 用域名访问 → 必须备案
  • 服务器在中国香港 / 新加坡 / 日本 → 不需要备案（但延迟高一些）
  • 只用 IP 访问、不绑域名 → 不需要备案（你现在就是这种状态）

不备案会怎样

不是"罚款"，而是更直接的：域名解析到大陆服务器后，80 / 443 端口会被服务商阻断，别人打开就是超时或一个拦截提示页。技术上完全通，就是被拦了。

个人备案要准备什么

  • 身份证正反面、手持身份证照片
  • 域名证书（在域名控制台能下载）
  • 真实性核验单（系统里生成，打印签字再拍照上传）
  • 手机号、邮箱，部分省份还要居住证 / 社保（看你身份证归属地）
  • 网站名称和简介：不能带"博客""论坛""新闻"这类需要前置审批的词，写"个人技术分享"最稳

要多久

腾讯云初审 1–3 个工作日，然后提交管局，管局审核 7–20 个工作日（各省不同，山东、江苏一般 10 天左右）。这期间域名不能对外提供访问，所以建议先买域名、先提交备案，服务器这边先用 IP 调试。

一个容易忽略的点：备案是绑在服务器上的（严格说是绑在接入商和 IP 上）。你换服务器、换服务商，备案要变更接入。所以别频繁搬服务器。

7. HTTPS 是怎么来的

HTTPS = HTTP + TLS 加密。要做到这件事，需要一张证书，证明"这个域名确实是你的"。

流程是这样：证书颁发机构（CA）核实你有域名控制权 → 签发证书 → 服务器配置上这张证书 → 浏览器访问时查验证书有效 → 握手加密 → 地址栏出现小锁。

要花钱吗

不需要。Let's Encrypt 提供完全免费的证书，90 天有效期，可以自动续期。你用的 Caddy 有个杀手级特性：配好域名它自己去申请、自己去续期，你什么都不用做。

xiaowang.com {
    root * /var/www/personal-site
    file_server
}
# 就这三行，Caddy 自动搞定证书和 HTTPS 跳转

前提是：域名已经解析到这台服务器，并且 80 / 443 端口放通。这也是为什么备案和 HTTPS 的顺序是——先域名、再解析、再备案，最后 HTTPS。

8. 三条路线怎么选

路线地址长什么样备案成本适合
只用 IP（现在） 154.8.177.56 不用 0 自己看、调试、给朋友临时看
域名 + 备案 xiaowang.com 必须 域名约 60 元/年 正式对外，推荐
域名 + 免备案 xiaowang.com 不用 域名 + 香港节点略贵 不想等备案、面向海外

我的建议：先在现有大陆服务器上用 IP 把站做好，同时买域名 + 提交备案，等备案下来直接切域名 + 开 HTTPS。两条线并行，一天都不浪费。

9. 新手最容易踩的坑

  • 以为买了域名就能访问——不配解析，域名指向的是注册商的占位页。
  • 忘了放通端口——服务器上服务跑得好好的，防火墙只开了 22，外面永远打不开。云厂商的防火墙和机器里的防火墙是两套，都要看。
  • 备案期间用域名访问——会被拦，还容易触发审核疑问。备案期间老老实实用 IP。
  • 网站名写"XX博客"——备案容易被退，写"个人技术分享"通过率高得多。
  • 只配了 www 没配裸域——用户输 xiaowang.com 打不开，输 www. 才行。两个都配上，或者用一个 301 跳到另一个。
  • 证书过期没续——Let's Encrypt 只有 90 天。用 Caddy 自动续期，或者用云厂商的免费证书但要记着换。
  • 以为快照等于备份——快照回滚是整盘覆盖，之后的数据全没了。要备份就单独存一份文件出去。

10. 你现在的位置

服务器 ✓→ 网页文件 ✓→ IP 可访问 ✓→ 买域名→ 解析→ 备案→ HTTPS

前三步已经完成了。剩下四步里，只有"备案"需要等（10–20 个工作日），其他都是几分钟的事。

所以最划算的动作是：今天就把域名买了、备案提交了，等审批的这三周里，我陪你把网站内容一点点填实。
